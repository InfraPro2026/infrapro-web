# InfraPro Web 1.0

Sitio estático para InfraPro México.

## Archivos

- `index.html`
- `css/styles.css`
- `js/script.js`
- `images/logo-infrapro.png`

## Publicación sugerida

1. Crear cuenta en GitHub.
2. Crear repositorio llamado `infrapro-web`.
3. Subir estos archivos.
4. Crear cuenta en Vercel.
5. Importar el repositorio.
6. Publicar.
7. Conectar el dominio `infrapro.mx`.
